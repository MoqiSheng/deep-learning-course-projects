# 图像分类与错例分析

计算机视觉 · 基础　｜　卷积网络 · 混淆矩阵

**研究问题**　两件上衣为什么容易被分错？

## 数据准备

取 28 × 28 灰度图与十类标签。按官方训练集和测试集划分，再从训练集划出验证集。保留类别名与编号对照。 [数据入口 · Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist)

## 实验步骤

1. **建立基线**　将像素展平，训练线性分类器，记录各类别召回率。
2. **完成对照**　在同一划分上训练两层卷积网络。固定种子，对比加入与去除随机平移增强后的结果。
3. **解释结果**　找出混淆次数最多的一对类别。并列展示六张错误样本，用轮廓、纹理或视角解释错误。

## 项目交付

提交混淆矩阵、六张错例及模型对照表。记录数据版本、划分方式、训练配置与运行命令，以便另一组复现实验。
