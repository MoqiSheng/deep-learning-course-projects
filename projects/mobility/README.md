# 基于签到序列的下一位置预测

城市计算 · 创新　｜　轨迹建模 · Top-K 推荐

**研究问题**　面对一段已知轨迹，能否把下一站排进前三？

## 数据准备

保留匿名用户、地点编号和时间戳。按时间先后组织历史，仅从训练时段构造候选地点与访问频次。 [数据入口 · Stanford SNAP · Gowalla](https://snap.stanford.edu/data/loc-gowalla.html)

## 实验步骤

1. **建立基线**　使用用户最常访问地点排序，历史不足时回退到训练集热门地点。记录 Top-3 命中率和冷启动比例。
2. **完成对照**　与基于上一站的转移模型、地点嵌入加 GRU 的序列模型对比。用同一候选集，统一处理未见地点。
3. **解释结果**　按轨迹长度分组分析命中率。用匿名地点编号画一段失败轨迹，解释通勤规律或罕见出行对排序的影响。

## 项目交付

提交轨迹示意图、三个候选地点和分组命中率。记录数据版本、划分方式、训练配置与运行命令，以便另一组复现实验。
