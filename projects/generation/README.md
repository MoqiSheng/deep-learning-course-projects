# 字符级文本生成

自然语言处理 · 基础　｜　循环网络 · 采样温度

**研究问题**　为什么同一个开头能写出不同的续文？

## 数据准备

下载纯文本，去除电子书头尾说明。按章节划分训练和验证材料，切分后再生成定长字符窗口。 [数据入口 · Project Gutenberg · Alice’s Adventures in Wonderland](https://www.gutenberg.org/ebooks/11)

## 实验步骤

1. **建立基线**　统计相邻字符的转移频率，构造二元语言模型。未见字符回退到训练集字符频率。
2. **完成对照**　用 GRU 预测下一字符。保持提示词与种子相同，比较温度 0.6、1.0、1.4 时的等长续文。
3. **解释结果**　在未见章节上比较平均负对数似然，并标记重复片段和明显断句错误。解释流畅度与多样性的取舍。

## 项目交付

提交同提示词三组续文、验证损失和重复片段标注。记录数据版本、划分方式、训练配置与运行命令，以便另一组复现实验。
