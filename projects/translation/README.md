# 注意力机制与机器翻译

自然语言处理 · 拓展　｜　Seq2Seq · 注意力

**研究问题**　长句翻译时，哪些词被漏掉了？

## 数据准备

选择一组中英语料，保留来源与归属。按源句去重分组后划分数据，避免同句的不同译本跨集合。 [数据入口 · Tatoeba 双语句对下载页（含归属信息）](https://www.manythings.org/anki/)

## 实验步骤

1. **建立基线**　训练不带注意力的编码器—解码器，按源句长度分组检查漏译。
2. **完成对照**　保持词表、数据和训练预算一致，加入注意力层。在同一长句上输出译文和逐词权重矩阵。
3. **解释结果**　选一处漏译，把译文与参考句对齐。讨论注意力高权重是否与正确翻译一致，并举出反例。

## 项目交付

提交长短句对照、注意力热力图和一例漏译分析。记录数据版本、划分方式、训练配置与运行命令，以便另一组复现实验。
