# 皮肤镜图像病灶分割

医学影像 · 创新　｜　U-Net · Dice

**研究问题**　低对比度边缘最容易漏分在哪里？

## 数据准备

从官方入口获取皮肤镜图像及对应掩膜，核对使用条款。成对读取图像和掩膜，缩放掩膜时使用最近邻插值。 [数据入口 · ISIC Challenge · 2018 Task 1](https://challenge.isic-archive.com/data/)

## 实验步骤

1. **建立基线**　用训练集选定灰度阈值形成二值掩膜。在保留集上计算逐图 Dice，并记录预处理方法。
2. **完成对照**　训练轻量 U-Net。对图像和掩膜同步裁剪或翻转；验证时比较区域重叠和边缘漏分。
3. **解释结果**　从低对比度、毛发遮挡两种情形中各选一例，将标注轮廓和预测轮廓叠加，标明过分割与欠分割区域。

## 项目交付

提交原图与双轮廓叠图、逐图 Dice 分布及错例说明。记录数据版本、划分方式、训练配置与运行命令，以便另一组复现实验。
